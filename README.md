
# EQUO - Siamo pari.
App spese casa condivisa - come MotoGarage.

## Setup
1. npm install
2. copia .env.example in .env e metti chiavi Supabase
3. npm run dev

## Deploy su Bolt
- Trascina tutta la cartella su bolt.new
- Aggiungi env VITE_SUPABASE_URL e VITE_SUPABASE_ANON_KEY
- Publish -> rinomina in equo
